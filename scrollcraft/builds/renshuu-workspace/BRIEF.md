# Renshuu. Scroll Craft adaptation

User-authorized adaptation of an existing learning application. The brief reuses the user's existing direction; authored implementation decisions are identified below. No new brand interview or media generation is needed for this bounded interface update.

## Evidence and creative scope

- User asks for the Renshuu repository to be analysed and upgraded: clean, professional graphics, animation, preferably 3D. The user then asks to install scroll-craft and apply it to this project.
- Existing product: ASP.NET Core Razor Pages quiz application. Real SQL data, subject folders, timed attempts, results, wrong-answer review and content administration.
- Preserve the current light/cobalt identity, Vietnamese copy, app navigation and all server form handlers.

## Eight brief topics

1. **Vibe:** clean, professional, dimensional. Existing user direction; no external reference brand is assumed.
2. **Journey:** current learning workflow: choose a subject, configure an attempt, answer, see feedback, revisit wrong questions. Existing product evidence.
3. **Energy:** authored decision: one expressive opening, then calm controls and readable content.
4. **Feeling and memorable moment:** authored decision: confidence from seeing a real study session take shape as its subject/count change.
5. **Signature move:** authored decision: a session stack unfolds into separated planes as the opening leaves the viewport; each plane represents an actual part of the selected session. Mode controls switch between practice and wrong-answer review, using real counts.
6. **Aesthetic range:** premium-minimal, inferred directly from the user's clean/professional requirement.
7. **World or scenes:** authored decision: a short live working surface. No continuous film, artificial pinning or cinematic page-length expansion.
8. **Assets:** existing app, icons and real subject data. CSS 3D and real markup. No generated photos/video, API calls or invented achievements.

## Feeling curve. Written before the score

1. Orientation: familiar sidebar, a readable title and a real session preview.
2. Confidence: selected subject and question count visibly update the dimensional session stack. **Peak.**
3. Control: a compact form lets the learner choose time and start a real attempt.
4. Clarity: the subject library and review shortcuts resolve into the next useful action.

Tell-someone sentence: the study workspace where your selected session takes shape before you start it.

## Grammar and gate

**Live surface.** The app itself is running; navigation and input are functional. Filmic one-shot and continuous world add unnecessary film/scroll time; chaptered editorial and typographic poster prioritize reading; gallery prioritizes media; split stage and rhythmic cutlist add structural changes unnecessary for this bounded dashboard enhancement.

Registry has no previous build rows. First-build gate passes without comparisons. Existing app chrome is deliberately preserved. This is not a new marketing landing page.

## Score

| Beat | Devices | Purpose |
| --- | --- | --- |
| Session preview | Parallax + bounded pointer depth + custom --sc-p fan | Distinct planes, actual selected-session values; no fake quiz result. |
| Real totals | Once-only count | Reveal real database counts; final values remain visible and screen-reader stable. |
| Practice form | Once-only entry | A short entrance, no gated input and no pinned scroll. |
| Library and review | Decorative reveal + static functional controls | Resolve the route into actual search/selection/review controls. |

Essential text and form controls never fade away with scroll. Every section remains in normal document flow. Motion-off, reduced-motion and JavaScript-off states are complete. Mobile has a separate composition and shorter layer travel. There is no authored empty scroll.
